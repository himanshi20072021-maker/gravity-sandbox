# Newton's Nightmare: Anti-Gravity UI Sandbox 🌌

An interactive, high-performance 2D physics sandbox that transforms traditional static web user interface components (cards, badges, forms, and inputs) into dynamic, kinetic objects governed by a custom real-time physics solver.

## ✨ Engineering Features

* **Custom Kinematics Solver:** Written completely from scratch in vanilla JavaScript using an object-oriented approach to compute real-time acceleration vectors, velocity damping (air resistance), and elastic surface collision matrices.
* **Dynamic Node Spawner:** Intercepts runtime keyboard events on text inputs to programmatically instantiate new interactive UI blocks, dynamically styling them with randomized neon spectrum coordinates.
* **Gravitational Vortex Singularity (Black Hole):** Click-and-hold vectors generate a space distortion field that smoothly warps object layout points, forces elements to implode to zero visibility inside the core, and produces an omnidirectional kinetic explosion upon mouse release.
* **Automated Object Alignment:** Integrates a physics bypass engine that uses smooth linear interpolation algorithms to recall and guide elements back to their pristine grid homes once external forces settle.
* **Mathematical Audio Synthesis:** Leveraged the browser's native **Web Audio API** to generate retro 8-bit arcade tones directly out of continuous wave equations, shifting frequencies smoothly based on interaction states.

## 🛠️ Tech Stack & Architecture

* **Languages:** JavaScript (ES6+), HTML5, CSS3
* **APIs & Optimization:** Web Audio API, hardware-accelerated CSS Transforms, and `requestAnimationFrame` frame-rate rendering loops.
* **Design Pattern:** Object-Oriented Programming (OOP) via customized structural state classes.
